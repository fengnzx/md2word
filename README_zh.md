# Markdown转Word转换工具

一个基于AI驱动的在线工具，用于将Markdown文档转换为高质量的Word文档。

## 功能特点

- 🔄 **智能格式转换**：完美保留Markdown中的标题、列表、表格、代码块、图片等格式元素
- 🤖 **AI增强功能**：集成AI模型，优化文档内容和格式
- ⚡ **实时状态监控**：可视化进度条显示转换状态
- 📁 **批量处理**：支持多文件同时转换
- 🔐 **安全可靠**：本地处理API密钥，确保数据安全
- 📱 **响应式设计**：适配桌面端、平板和移动设备

## 技术架构

- **前端**：React + TypeScript + Vite
- **后端**：Node.js + Express
- **转换引擎**：Mammoth + Turndown
- **AI集成**：OpenAI兼容API

## 安装与使用

### 环境要求

- Node.js >= 16.0.0
- npm 或 yarn

### 本地开发

1. 克隆项目：
```bash
git clone <repository-url>
cd md2word
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

4. 访问 `http://localhost:5173` 查看应用

### 生产部署

1. 构建项目：
```bash
npm run build
```

2. 启动生产服务器：
```bash
npm run start
```

## 使用指南

1. 在拖放区域上传Markdown文件（.md或.markdown格式）
2. 配置AI模型参数（可选）：
   - 输入API地址
   - 选择或输入模型名称
   - 提供API密钥
3. 点击转换按钮开始处理
4. 查看实时转换进度
5. 转换完成后下载Word文档

## AI增强功能

通过集成AI模型，本工具可以：
- 优化文档结构和格式
- 提升内容质量
- 自动修复格式问题
- 统一文档风格

## 安全说明

- 所有文件处理均在服务器端完成
- 用户API密钥仅在客户端存储，不会发送到服务器
- 实施文件大小限制（最大20MB）和格式验证
- 防止恶意文件上传的安全措施

## 支持的Markdown语法

- 标题（H1-H6）
- 粗体、斜体、删除线
- 有序列表和无序列表
- 表格（包括合并单元格）
- 代码块（保留语法高亮）
- 图片（本地和网络链接）
- 引用块、水平分隔线、脚注

## 常见问题

### Q: 支持哪些文件格式？
A: 目前支持.md和.markdown格式的Markdown文件。

### Q: 文件大小有限制吗？
A: 是的，单个文件最大支持20MB。

### Q: AI功能如何工作？
A: AI功能通过集成的API对文档内容进行分析和优化，提升转换质量。

### Q: 如何配置AI模型？
A: 在界面上输入兼容OpenAI的API地址、模型名称和API密钥即可启用AI增强功能。
